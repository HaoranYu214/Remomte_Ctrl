# Official SMU examples

[English](#english) | [中文](#中文)

## English

- [System Mode](System%20Mode/README.md): complete sweeps and buffered readout.
- [User Mode](User%20Mode/README.md): individual source configuration, triggering, and spot measurements.

Maintained entries are listed under [SMU I-V](../../../measurements/smu/iv/README.md). System Mode/instrcomms.py is the examples' own communication implementation; maintained code uses keithley4200.transport.

Parameter source: [manual limits and mode reference (Chinese)](../../manuals/PARAMETER_LIMITS.md).

## 中文

### SMU 官方示例

- [System Mode](System%20Mode/README.md)：完整扫描和缓存读数。
- [User Mode](User%20Mode/README.md)：逐条配置源、触发和读取单点。

维护入口见 [SMU I-V](../../../measurements/smu/iv/README.md)。System Mode/instrcomms.py 是示例自身的通信实现；维护库统一使用 keithley4200.transport。

参数依据：[手册限制与模式速查](../../manuals/PARAMETER_LIMITS.md)。
