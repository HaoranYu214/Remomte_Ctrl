# Official PMU example

[English](#english) | [中文](#中文)

## English

1 chan sweep without plotting.py demonstrates a single-channel pulse sweep and data retrieval. Use it to compare vendor configuration and command ordering. Maintained alternatives are listed under [PMU experiments](../../../measurements/pmu/README.md).

The script is reference code, not a shared-library import or a normal production experiment entry.

Parameter source: [manual limits and mode reference (Chinese)](../../manuals/PARAMETER_LIMITS.md).

## 中文

### PMU 官方示例

1 chan sweep without plotting.py 演示单通道脉冲扫描和读数。用于对照厂商的配置与命令顺序。维护中的替代入口见 [PMU 实验](../../../measurements/pmu/README.md)。

本目录的脚本是参考代码，不参与维护库的公共导入，也不作为正常实验主入口。

参数依据：[手册限制与模式速查](../../manuals/PARAMETER_LIMITS.md)。
