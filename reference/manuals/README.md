## English

The [parameter limits and mode reference](PARAMETER_LIMITS.md) maps commonly used voltages, current ranges, compliance, timing, and mode values to manual pages. It distinguishes project conventions from verified manual requirements.

The original [KXCI manual](4200A-KXCI-907-01D_May_2024.pdf) includes SMU, CVU, and PGU/PMU chapters.

Parameter source: [manual limits and mode reference (Chinese)](PARAMETER_LIMITS.md).
