# Manuals and parameter reference

[English](#english) | [中文](#中文)

## English

The [parameter limits and mode reference](PARAMETER_LIMITS.md) maps commonly used voltages, current ranges, compliance, timing, and mode values to manual pages. It distinguishes project conventions from verified manual requirements.

The original manual is in [smu](smu/README.md). Despite that directory name, the KXCI manual includes SMU, CVU, and PGU/PMU chapters.

Parameter source: [manual limits and mode reference (Chinese)](PARAMETER_LIMITS.md).

## 中文

### 手册与参数速查

[参数限制与模式说明](PARAMETER_LIMITS.md) 把本库常用电压、电流、限流、时间及模式值对应到手册页码，并明确区分代码约定与已核实的手册条款。

原文在 [smu](smu/README.md)。目录名称虽为 smu，实际 KXCI 手册同时包含 SMU、CVU、PGU/PMU 章节。

参数依据：[手册限制与模式速查](PARAMETER_LIMITS.md)。
